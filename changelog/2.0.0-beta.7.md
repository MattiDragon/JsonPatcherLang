## Core language
* Variables can now again be captured by functions within their initializers
  * This makes OOP easier and recursion less ugly

## Analysis tools
* Made mutable variables have uncertain types in order to prevent incorrect errors
* Object initializers no longer form dictionary types as easily
  * Empty object and objects with varying key types are now treated as `object` instead of `never{}`
* Unnecessary `never` entries are now removed from unions

## Language server
* Fixed infinite recursion bug in type printing for hovers
