## Core language
* Variables can now again be captured by functions within their initializers
  * This makes OOP easier and recursion less ugly

## Type checking
* Made mutable variables have uncertain types in order to prevent incorrect errors
* Object initializers no longer form dictionary types as easily
  * Empty object and objects with varying key types are now treated as `object` instead of `never{}`
* Unnecessary `never` entries are now removed from unions
* **Method calls on primitives now correctly type check with the correct argument count**
* `foreach`-loops and function declarations now correctly infer variable types
* **The type checker now notices missing function arguments**
* The type checker is now more lenient with union types
* Binary expressions are now type checked
* **Generic functions are now correctly type checked**

## Documentation tool
* Added deprecation warnings to legacy keywords

## Language server
* Fixed infinite recursion bug in type printing for hovers
* Added inlay type hints for variables
* Hover on variables now correctly displays function types
* Variable hover should now show the type more often
