## Core language
* Variables can now again be captured by functions within their initializers
  * This makes OOP easier and recursion less ugly

## Type checking
* Made mutable variables have uncertain types in order to prevent incorrect errors
* Object initializers no longer form dictionary types as easily
  * Empty object and objects with varying key types are now treated as `object` instead of `never{}`
* Unnecessary `never` entries are now removed from unions
* **Method calls on primitives now correctly type check with the correct argument count**
* `foreach`-loops and function declarations now correctly infer variable types
* **The type checker now notices missing function arguments**
* The type checker is now more lenient with union types
* Binary expressions are now type checked
* **Generic functions are now correctly type checked**
* Types can now be manually indicated using comments
  * Use `# @@type <type>` to set the type of a variable
  * Use `# @@arg <name> <type>` to set the type of a function argument
* `functions.then` and `functions.bind` are now special-cased and will apply nicely to function types

## Documentation tool
* Added deprecation warnings to legacy keywords
* Tags are now regular doc line with `@` as the first symbol
  * `#@ method string` -> `#| @method string`

## CLI tools
* The formatter is now available as a CLI tool
  * It should now work correctly on most code

## Language server
* Fixed infinite recursion bug in type printing for hovers
* Added inlay type hints for variables
* Hover on variables now correctly displays function types
* Variable hover should now show the type more often
* Added support for document highlights, which show other usages of the symbol at the cursor
* Added option to suppress diagnostics
  * Use `# @@suppress <diagnostic-id>` to suppress for one line
  * Use `# @@suppress <diagnostic-id> <n> lines` to suppress for multiple lines
  * Use `# @@suppress <diagnostic-id> file` to suppress for the whole file
  * Use `# @@suppress <diagnostic-id> <begin|end>` to suppress for a region
* Now supports formatting (still somewhat broken)
* Conditions on global libraries are now checked
  * Information needed to check conditions is read from `jsonpatcher-workspace.json` files ([schema available here](https://raw.githubusercontent.com/MattiDragon/JsonPatcherLang/refs/heads/2.0/tools/lang-server/jsonpatcher-workspace.schema.json))
