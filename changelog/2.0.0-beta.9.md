## Standard library
* `reflection` is now correctly marked as a regular library
* Reflection now ignores bridge methods
  * Fixes issues with needless duplicate method errors
* Switched to using `@@doc_namespace std` for stdlib

## Language
* Added support for string interpolation using `\{}` syntax

## Type Checking
* Added new, mostly rewritten, typechecker
  * Better handling of generic functions
  * Performs bidirectional type checking, which fixes many inference issues

## Doctool
* Fixed bug where trailing data was ignored after global library declarations
* Add `@@doc_namespace` for declaring default doc namespaces

## Language Server
* Add `--stdio` argument to use stdio instead of a socket, allows more clients to use the LS
* Improved semantic tokens a bunch, although mostly in areas already covered by TextMate grammars
